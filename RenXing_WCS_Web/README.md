# RenXing WCS Web 3

Vue 3 + Vite + TypeScript + Element Plus version of the WCS monitor.

## Commands

```bash
npm install
npm run dev
npm run type-check
npm run build
```

The WCS API origin defaults to the current Web UI host on port `5200` in a browser. Override it with `VITE_WCS_API_URL` when the API is deployed elsewhere.
