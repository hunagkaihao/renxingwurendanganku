# WCS 日志

## 控制台与原有 SQLite 日志

控制台使用 Serilog 和 `AnsiConsoleTheme.Code`，在应用创建、读取 YAML 和初始化
依赖注入之前建立日志。启动或运行失败时输出中文提示、完整异常及内部异常链，退出时刷新日志。
若日志组件本身初始化失败，则使用标准错误输出兜底。

Serilog 作为 `ILoggerProvider` 接入，保留原有 `ILoggerFactory`。
Host 模块只追加 `SqliteLoggerProvider`，不再清空 provider 或重复注册默认控制台。
SQLite 的事件编号筛选（`-3270`、`14`）、日志等级、表结构和前端查询接口保持不变。

控制台显示时间、英文等级缩写、来源、消息和异常，不显示中文等级标识。
等级使用 VRB/DBG/INF/WRN/ERR/FTL，日志提示正文继续使用简体中文。例如：

```text
[2026-08-31 10:00:00.000 INF]  WCS 服务已启动。按 Ctrl+C 停止服务。
```

直接使用原生 `AnsiConsoleTheme.Code`，不覆盖主题样式，也不按等级拆分控制台分支。
等级、正文、字符串、数字等分别采用主题默认配色，不再强制整条日志跟随等级变色。
控制台只配置一个 Console sink；样式只作用于控制台，不写入日志正文或 SQLite。

原有控制台对 EF Core、ASP.NET Core、ABP 和 HttpClient 分类的 Warning 阈值在
Serilog 中保留。`ILogger` 的通用过滤仍使用 `Logging:LogLevel`；直接通过
`Serilog.Log` 输出的启动、停止和初始化失败信息不依赖该过滤配置。
默认英文生命周期 Information 日志仅在 Serilog 控制台侧过滤，由中文启停、运行环境和
监听地址提示替代；该分类的 Warning/Error 不过滤。

`Ctrl+C` 字样及宿主的正常停止行为保持不变，没有接管键盘、增加 `ReadKey` 或修改退出信号。
ANSI 颜色是否显示取决于终端能力，重定向或不支持 ANSI 的环境不强制输出颜色控制码。

## 中文化边界

- 可安全修改的启动/停止提示、接口日志说明和业务提示使用简体中文。
- 日志占位符名称、协议字段、PLC 点位、类名、路径、设备编码等保持原样。
- `INFO`、`ERROR`、`WARN` 等数据库等级值供前端筛选使用，不翻译。
- 异常消息、内部异常及堆栈保留原文，不强行翻译第三方框架内容，也不改变线程区域设置。
- 同时写入订单状态、Redis 或可能被业务消费的执行信息保留原样，避免改变业务行为。
- SQLite 日志组件自身的失败使用带中文说明的直接控制台输出，不再调用自身日志链路。
  这类兜底输出不经过 Serilog 主题。
- PLC 客户端初始化失败的直接输出、设备报警诊断输出保留原来的调用路径，仅中文化说明文字。
  这些既有直接输出同样不经过 Serilog 主题；业务异常原文不作全文替换。
